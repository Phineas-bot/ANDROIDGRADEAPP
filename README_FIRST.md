## 🎯 Features

**Grade Calculation**
- Input CA score (0-40)
- Input Exam score (0-60)
- Automatic total calculation
- Letter grades (A-F)
- Grade points (4.0-0.0)

**GPA System**
- Calculate from multiple courses
- Automatic averaging
- PASS/FAIL determination
- Semester summary

**Data Management**
- Add courses
- View all courses
- Delete courses
- Persist to database

**Modern UI**
- Material Design 3
- Jetpack Compose
- Color-coded grades
- Responsive layout
